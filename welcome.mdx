The SOLO Network API provides a single integration point for accessing identity verification, compliance screening, and financial data across multiple data providers. Rather than integrating with dozens of vendors individually, you connect to SOLO and access standardized **templates** that normalize data from upstream sources.

## How it works

Every verification in SOLO follows the same two-step pattern:

1. **Query** — Retrieve existing data for a subject (consumer or business) from the network.
2. **Furnish** — Submit new data into the network for a subject.

These operations are exposed through **templates** — standardized schemas for each data domain (e.g., Address Verification, Document Capture, Employment Verification). Templates can be composed into **use case bundles** for common workflows like KYC or KYB.
