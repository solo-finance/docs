```
{category}/{filename}.xlsx
```

## KYC Certificate Policy

**Directory**: `kyc_cert_policy/`

Defines Know Your Customer verification policies. Each row configures a named policy with operation flags that control which verification steps are active.

<Card title="Download Template" icon="download" href="https://raw.githubusercontent.com/solo-finance/docs/dev/sftp/templates/kyc-cert-policy-template.xlsx">
  KYC Certificate Policy Template (.xlsx)
</Card>

**Upload Path**:
```
kyc_cert_policy/{filename}.xlsx
```

### Required Columns

| Column | Type | Description |
|---|---|---|
| `kyc_policy_name` | string | Name of the KYC policy |
| `start_date` | date | When the policy becomes active |
| `entity_type` | string | Must be `Consumer` |

### Operation Flag Columns (Required)

Each flag enables or disables a verification step. Values: `true`/`false` or `1`/`0`.

| Column | Description |
|---|---|
| `document_capture` | Require document image capture |
| `document_review` | Require document attribute review |
| `biometric_capture` | Require biometric capture |
| `biometric_review` | Require biometric attribute review |
| `liveness_capture` | Require liveness check capture |
| `liveness_review` | Require liveness evidence review |
| `address_capture` | Require address capture |
| `address_verification` | Require address verification |
| `identity_corroboration` | Require identity corroboration |

### Optional Columns

| Column | Type | Description |
|---|---|---|
| `end_date_if_applicable` | date | When the policy is deprecated |
| `data_source` | string | Source of verification data |
| `name_of_furnisher_storage_system_used` | string | Storage system identifier |
| `name_of_storage_system_other_only` | string | If storage system is "Other" |
| `entity_consent_level` | string | Level of consumer consent obtained |
| `entity_consent_mechanism_type` | string | How consent was collected |
| `name_of_entity_consent_mechanism_other_only` | string | If consent mechanism is "Other" |
| `permitted_purpose_scope_s` | string | Permitted purpose scopes |

## KYB Certificate Policy

**Directory**: `kyb_cert_policy/`

Defines Know Your Business verification policies. Same structure as KYC policies but with business-specific operation flags.

<Card title="Download Template" icon="download" href="https://raw.githubusercontent.com/solo-finance/docs/dev/sftp/templates/kyb-cert-policy-template.xlsx">
  KYB Certificate Policy Template (.xlsx)
</Card>

**Upload Path**:
```
kyb_cert_policy/{filename}.xlsx
```

### Required Columns

| Column | Type | Description |
|---|---|---|
| `kyb_policy_name` | string | Name of the KYB policy |
| `start_date` | date | When the policy becomes active |
| `entity_type` | string | Must be `Business` |

### Operation Flag Columns (Required)

| Column | Description |
|---|---|
| `business_identity_verification` | Require business identity verification |
| `business_ownership_control_verification` | Require ownership and control verification |
| `business_risk_compliance_verification` | Require risk and compliance assessment |

### Optional Columns

Same optional metadata columns as KYC Certificate Policy (data source, storage system, consent fields, permitted purpose scopes).

## Programs

**Directory**: `programs/`

Configures network programs that link KYC and KYB policies together. Each program can reference up to 5 KYC policies and 5 KYB policies.

<Card title="Download Template" icon="download" href="https://raw.githubusercontent.com/solo-finance/docs/dev/sftp/templates/programs-template.xlsx">
  Programs Template (.xlsx)
</Card>

**Upload Path**:
```
programs/{filename}.xlsx
```

### Required Columns

| Column | Type | Description |
|---|---|---|
| `program_number` | string | Unique program identifier (header may also appear as `Program #`) |
| `program_name` | string | Display name of the program |
| `kyc_policy_1_name` | string | Name of the first KYC policy |
| `kyb_policy_1_name` | string | Name of the first KYB policy |

### Policy Slot Columns

Each policy slot (1 through 5) follows this pattern:

| Column Pattern | Type | Description |
|---|---|---|
| `kyc_policy_{n}_name` | string | KYC policy name for slot N |
| `kyc_policy_{n}_start` | date | Effective start date for slot N |
| `kyc_policy_{n}_end_if_applicable` | date | End date for slot N (optional) |
| `kyb_policy_{n}_name` | string | KYB policy name for slot N |
| `kyb_policy_{n}_start` | date | Effective start date for slot N |
| `kyb_policy_{n}_end_if_applicable` | date | End date for slot N (optional) |

Where `{n}` is 1 through 5. If a slot's name is provided, its start date is required.

<Tip>
  Policy names must match policies that have already been uploaded via the KYC or KYB Certificate Policy categories. Upload policies before programs.
</Tip>

## KYC Furnish Data

**Directory**: `kyc_furnish_data/`

Uploads consumer onboarding records for KYC certificate generation. Each row represents an individual consumer tied to a program.

<Card title="Download Template" icon="download" href="https://raw.githubusercontent.com/solo-finance/docs/dev/sftp/templates/kyc-furnish-data-template.xlsx">
  KYC Furnish Data Template (.xlsx)
</Card>

**Upload Path**:
```
kyc_furnish_data/{filename}.xlsx
```

### Required Columns

| Column | Type | Description |
|---|---|---|
| `file` | string | Furnisher file number (unique row identifier; header may appear as `File #`) |
| `social_security_number` | integer | Consumer SSN (used as upsert key) |
| `date_of_birth` | date | Consumer date of birth |
| `program_name` | string | Program this record belongs to |
| `application_date` | datetime | When the consumer applied |

### Optional Columns

| Column | Type | Description |
|---|---|---|
| `first_name` | string | Consumer first name |
| `last_name` | string | Consumer last name |
| `phone_number` | string | Consumer phone number |
| `email` | string | Consumer email address |
| `furnisher_id` | string | External furnisher identifier |
| `furnisher_federation_id` | string | External federation identifier |

## KYB Furnish Data

**Directory**: `kyb_furnish_data/`

Uploads business onboarding records for KYB certificate generation. Each row represents a business entity tied to a program.

<Card title="Download Template" icon="download" href="https://raw.githubusercontent.com/solo-finance/docs/dev/sftp/templates/kyb-furnish-data-template.xlsx">
  KYB Furnish Data Template (.xlsx)
</Card>

**Upload Path**:
```
kyb_furnish_data/{filename}.xlsx
```

### Required Columns

| Column | Type | Description |
|---|---|---|
| `file` | string | Furnisher file number (unique row identifier; header may appear as `File #`) |
| `business_tax_identifier_value` | string | Tax identifier (e.g., EIN) |
| `business_tax_identifier_type` | string | Type of tax identifier |
| `business_jurisdiction_of_formation` | string | Jurisdiction where business is formed |
| `program_name` | string | Program this record belongs to |
| `application_date` | datetime | When the business applied |

### Optional Columns

| Column | Type | Description |
|---|---|---|
| `business_legal_name` | string | Official legal name |
| `business_dba_name` | string | Doing-business-as name |
| `business_website_url` | string | Business website |
| `business_registration_identifier_from_jurisdiction_of_formation` | string | Registration number from jurisdiction |
| `furnisher_id` | string | External furnisher identifier |
| `furnisher_federation_id` | string | External federation identifier |
